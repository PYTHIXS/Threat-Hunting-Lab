# Scenario 3: Web Application Vulnerability

## Objective

Practice analyzing and reporting a web application security issue.

## Initial Signals

- A web app shows abnormal behavior under crafted requests
- Security scan or manual testing indicates injection or access control weakness
- The application processes user input without adequate validation

## Investigation Tasks

1. Confirm the vulnerability class
2. Determine affected versions and routes
3. Identify what data may be exposed
4. Assess exploitability and user interaction requirements
5. Recommend remediation and validation testing

## Evidence to Review

- Application logs
- Request and response traces
- Vulnerability scanner output
- Source code review
- WAF and reverse proxy logs

## Reporting Focus

- The issue and how it was validated
- Exposure and potential business impact
- Fix strategy and security controls to add

---

This scenario strengthens skills in vulnerability analysis, exploitability assessment, and reporting.
