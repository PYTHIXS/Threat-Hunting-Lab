# Exercise 03: Incident Defense and Response

## Scenario

A suspicious login and credential use pattern emerges across multiple systems.

## Tasks

1. Review identity and endpoint evidence
2. Determine whether the activity is compromised access or a false positive
3. Contain risk and reduce attacker movement
4. Recommend control improvements

## Deliverables

- Timeline
- Impact assessment
- Containment actions
- Control improvement recommendations

---

This exercise supports incident response and defensive posture development.
