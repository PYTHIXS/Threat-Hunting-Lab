# Vulnerability Triage Checklist

## Intake

- Asset identified
- Owner assigned
- Business impact estimated

## Assessment

- Vulnerability type known
- Affected software and version confirmed
- Exploitation conditions evaluated
- Public exploit availability reviewed

## Prioritization

- Severity assigned
- Exposure considered
- Threat intel checked
- Patch or workaround identified

## Remediation

- Patch or configuration fix planned
- Testing scheduled
- Compensating controls documented

## Verification

- Fix deployed and validated
- Re-test for the original issue
- Evidence captured for closure

---

This checklist helps standardize the process for evaluating and remediating findings.
