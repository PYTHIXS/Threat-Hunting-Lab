# Attack Matrix Reference

## Initial Access

- Phishing
- Exploit public-facing application
- Valid accounts
- Supply chain compromise

## Execution

- PowerShell
- WMI
- Rundll32
- Scheduled task
- Service creation

## Persistence

- Registry autoruns
- Scheduled tasks
- Services
- Startup folders
- SSH keys / admin credentials

## Privilege Escalation

- Local exploitation
- Token theft
- Credential dumping
- Abuse of misconfigured permissions

## Defense Evasion

- Obfuscation
- Living off the land binaries
- Process hollowing
- Masquerading

## Collection and Exfiltration

- Archive creation
- Compression and staging
- Transfer over web, DNS, or cloud storage

Use this matrix as a quick threat reference for books, labs, and investigations.
