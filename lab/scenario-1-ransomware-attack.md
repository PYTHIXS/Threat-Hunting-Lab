# Lab Scenarios

This document contains a set of realistic scenarios suitable for training, testing, and documentation.

## Scenario 1: Ransomware-like Activity

- Multiple endpoints show suspicious PowerShell activity
- Files are rapidly encrypted in a short time window
- Endpoint protection alerts are triggered
- The goal is to detect, contain, and report the behavior

## Scenario 2: Phishing Credential Harvest

- User receives a phishing email with a fake login portal
- Credentials are submitted to a malicious domain
- The investigation focuses on user activity, authentication logs, and web telemetry

## Scenario 3: Web Application Vulnerability

- An application is vulnerable to SQL injection or XSS
- The challenge is to validate the impact, identify affected hosts, and recommend mitigation

## Scenario 4: Lateral Movement

- Suspicious use of administrative tools across devices
- The hunt focuses on privilege escalation, remote execution, and suspicious service creation

## Scenario 5: Data Exfiltration

- Unusual uploads or outbound transfers are observed
- Investigators need to connect the sequence of events and quantify the exposure

## Lab Notes

Keep notes for each scenario:

- Hypothesis
- Evidence collected
- Timeline
- Findings
- Detection gaps
- Response actions
- Final report

---

Use these scenarios as templates for hands-on exercises and reporting practice.
