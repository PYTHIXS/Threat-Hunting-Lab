# Exercise 04: Reporting

## Scenario

You have completed an investigation and need to communicate the result to both technical and executive audiences.

## Tasks

1. Prepare a technical report
2. Prepare an executive summary
3. Define ownership and remediation steps
4. Identify monitoring changes to prevent recurrence

## Deliverables

- Technical report
- Executive summary
- Remediation plan
- Risk register entry

---

This exercise develops communication precision and evidence-based security reporting.
